# WebTomata

## ENGLISH

This is an open-source repository for WebTomata. This project is designed to make things related to theory of computation or automata and theory of languages on the web easier.

## BAHASA INDONESIA

Ini adalah repositori open-source untuk WebTomata. Proyek ini dirancang untuk memudahkan hal-hal yang berkaitan dengan teori komputasi atau automata dan teori bahasa di web.
