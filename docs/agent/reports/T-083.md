## 1. Pre-flight measurements (before any code change)

1. **`addRow` in `web/src/lib/editor/PdaLabelForm.svelte` (lines 100–107):**
   `addRow()` appends an empty row, awaits `tick()`, queries `.row-fields input`, selects `lastFirst = inputs[inputs.length - 3]` (the new row's `Baca` input), and calls `lastFirst?.focus()`. `onMount` (line 51) already called `first.scrollIntoView({ block: 'nearest', inline: 'nearest' })`; `addRow` had no `scrollIntoView`.
2. **Where `.rows` scrolls and target element:**
   `.rows` has `overflow-y: auto; max-height: 240px;` (`PdaLabelForm.svelte:329–335`), capped in the phone sheet by `PdaEditor.svelte:506–508` to `.pda-sheet :global(.pda-label-form .rows) { max-height: 72px; }`. Each `.row` has `rowTop === inputTop` and `rowBottom === inputBottom` (44 px tall grid, no vertical padding), so `lastFirst?.scrollIntoView({ block: 'nearest' })` scrolls the exact row box without an extra DOM query.
