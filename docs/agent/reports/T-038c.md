## 2. Implementation summary (amendment R1–R3 & Flaws 1–9)

- **UI & model:** Added `web/src/lib/grammar/GrammarToPdaTab.svelte` and pure model `web/src/lib/grammar/grammar-to-pda.ts` (copied stepper pattern from `GrammarCnfStepper.svelte`, no CNF/CYK changes). Uses `transitionLabel` from `web/src/lib/editor/diagram/pda-diagram.ts` (slash form `read / pop / push`).
- **Explicit trigger & stale guard (Flaw 7, AC4):** No engine call runs while hidden or on keystrokes. Clicking **Buat PDA** runs `cfgToPdaTopdown` or `cfgToPdaBottomup` once; switching method radios while a result exists re-runs once and restarts at step 1; any edit to the grammar immediately clears stale results and returns to **Buat PDA**.
- **Layout & title (`LIMITS.titleChars = 100`):** `cfgPdaLayout` places states in ascending `id` order at `(200 + i * 420, 220)` (420 units apart; `p` at `(200, 220)`, `q` at `(620, 220)` for F-ANBN). `buildConvertedPdaTitle` clamps the base name by Unicode code points so `"<name> (PDA atas-bawah)"` / `"(PDA bawah-atas)"` fits within `LIMITS.titleChars` (`100`). Empty grammar names fall back to `editor.untitled`.
- **Refusals & failures:** Engine refusals (`pda.cfg.symbol_clash`, `machine.limit_exceeded` at 64 RHS symbols, `api.too_long`, `api.invalid_grammar`, `alphabet.*`) render as a calm sentence; thrown/worker failures render `EngineNotice` with retry.
- **Lazy dictionary (R2, ADR 0050):** All 17 new keys (`workstation.tab_topda`, `grammar.to_pda_*`) live in `web/src/lib/i18n/grammar-to-pda-messages.ts`, imported only by `GrammarWorkstation.svelte`. Type-only union in `id.ts` adds **0 B** to first-load JS on every route.
- **Phone strip (R3):** Grammar phone strip now has 5 items (`Pustaka`, `Editor`, `CNF`, `CYK`, `Ke PDA`). `WorkstationPhoneTabs.svelte` uses `padding: 0 var(--space-2); white-space: nowrap;` so all 5 tabs fit on 1 row at 360 px with ≥ 44×44 px targets (`295.0 px` ID / `286.9 px` EN out of `336 px` available). Shared phone specs (`grammar-phone`, `language-phone`, `editor-bar-phone`, `pda-panel`, `cross/workstation-phone`) all pass.
- **Glossary & ADR:** Added `atas-bawah`, `bawah-atas`, `Buat PDA`, `Sudah ditambahkan` (`TODO(review)`) to `docs/glossary.md`, and wrote `docs/decisions/0066-grammar-to-pda-tab.md`.
- **Out-of-scope finding logged as `proposed` (T-087):** Pre-existing `.custom-card` in `GrammarWorkstation.svelte` nests `<button class="btn-delete">` inside `<div role="button">`, causing an axe `nested-interactive` violation on desktop whenever a custom grammar is present.
