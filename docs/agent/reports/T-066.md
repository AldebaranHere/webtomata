**AC4 is not met literally.** `sandbox.html` grows 71 bytes gzip (0.057% of the route) and the PDA entry chunk grows 1 byte gzip with its raw size unchanged. The reason is the shape the task decided: `placement.ts` is imported by the eager editor core, so the one copy now loads with the editor instead of with the lazy FSM table. The 179 bytes of the function moved out of the FSM table's lazy chunk (saving 66 gzip) and into the eager chunk (+69 gzip), and the two renamed route hashes in the app entry chunk add the remaining 2; the PDA copy disappeared from the PDA table chunk (saving 80 gzip). The PDA entry chunk's +1 is the renamed reference to the dynamic table chunk's hash (`BgNqDPav.js`), not new code. Summed over the changed chunks, the build is about 74 bytes gzip smaller and carries one copy fewer. The 170 KB budget is untouched (`sandbox.html` 122.7 KB).
