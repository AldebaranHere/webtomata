## 9. Decisions and deviations from the sheet

- **The transition index is the identity.** Every valid `PdaDocument` keeps its transitions in the
  engine's order: `addTransition` inserts with `comparePdaTransitions`, `parsePdaDocument` refuses an
  unsorted list, and `fromEnginePda` sorts. `step.transition` therefore indexes `doc.transitions`
  directly; no comparator is used at run time. This is why B7 was replaced.
- **The stack's text uses the document's separator** (`AA` for a one-character stack alphabet,
  `Z0 A` otherwise), as the diagram's labels and the table do; the sheet writes "A A", which is the
  multi-character form. The cells themselves are always one symbol each.
- **The rows and the step line count from 1**, per the amendment; the rows' numbers use the same
  step number, so the list and "Langkah n dari N" cannot disagree.
- **The head is one copy in the page.** It sits at the top of the open tab: the always-mounted
  Simulasi pane renders it while Simulasi is open, and the Tabel/Definisi pane renders its own while
  it is open. (Two copies at once made 27 runs fail on strict locators, and would have announced the
  badge and the checks twice.)
- **A stopped run's box is shown at once**, with the partial computation still steppable; accepted
  and rejected verdicts wait for the last step, as the FSM's do.
- **The used edge's stroke is the `from>to` group**; with wwᴿ's two transitions on q0→q0 both labels
  light up. Tested on F-DPDA, where each edge has one transition. T-085 is proposed for the exact
  stroke.
- **The list is not saved** and survives a tab switch only (the mode switch unmounts the
  workstation). ADR 0064 says so.
- **The tour's step 5** still says "Semuanya tersimpan di perangkat ini", which is not true for the
  PDA's list; I did not reword the shared step (the planner owns the tour's text) and proposed
  **T-086** for it.
