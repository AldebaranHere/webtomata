
# Reverse Engineering Rules

## Scope

Analyze only software that I own or have permission to examine.

Work on the specific feature I name.

Do not bypass licensing, DRM or access controls.

## Evidence

Every important conclusion must be classified as:

- OBSERVED
- INFERRED
- UNKNOWN

Include the file, function, address or other evidence location whenever available.

## Workflow

Start with an overview.

Do not dump the entire application.

Inspect only what is needed to explain the requested behavior.

Do not confuse static analysis with runtime proof.

## Reconstruction

Build original code from a behavioral specification.

Do not copy proprietary code or assets.

Write tests for every important behavior.

Stop when the requested behavior is understood or when remaining uncertainty is documented.
